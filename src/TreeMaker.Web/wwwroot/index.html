Toward a crease pattern

A crease pattern needs the tight paths to divide the leaves' outline into convex polygons with no leaf inside. Check that, close the polygons by adjusting edge lengths, then build the crease pattern.

    Close the polygons

    Keeps every leaf where it is and the scale fixed, and changes edge lengths so the pairs of a triangulation become tight, boundary pairs first. It then uses the least total strain that keeps that many tight.

    Build the crease pattern

    Fills every polygon with Lang's universal molecule: ridges where the polygon shrinks, hinges at the tree's internal nodes, and gussets where it splits. Then it folds the result and checks every facet.

    Alternating valley and mountain folds along elevation contours; 1 grid unit gives box-pleating-style pleats.
